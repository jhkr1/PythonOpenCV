# Face Recognition with OpenCV 🎯

컴퓨터 비전 기초를 학습하기 위한 프로젝트로, OpenCV를 활용하여 얼굴을 인식하고 시각적으로 표시하는 실습을 진행하였습니다.

---

## ✅ 프로젝트 목표 (Purpose)

- OpenCV 라이브러리를 활용한 이미지 처리 기초 학습
- Haar Cascade 알고리즘을 적용한 얼굴 탐지 구현
- 실시간 혹은 이미지 기반 얼굴 인식 워크플로우 이해
- 추후 딥러닝 기반 얼굴 인식 모델로의 확장 발판 마련

---

## 🧰 사용 기술 (Tech Stack)

| 영역             | 기술                             |
|------------------|----------------------------------|
| Language         | Python 3.10+                     |
| CV Library       | OpenCV (`cv2`)                   |
| Algorithm        | Haar Cascade Classifier          |
| IDE/Env          | Jupyter Notebook / Colab / VSCode|
